# Facebuilder Tools

An offline Android face modeling and tracking studio.

## MVP
- Face Builder workspace
- Face Tracker workspace
- Face Geo Tracker workspace
- Diffuse/albedo texture workflow
- Local GLB/OBJ model export

This repository is currently a functional Android project scaffold. Advanced face reconstruction, tracking, and texture processing are placeholders for the first implementation milestone.

## Build
Open the project in Android Studio and sync Gradle.
